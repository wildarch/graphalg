# GraphAlg Language Specification

The paper [Foundations of the GraphAlg Language](https://arxiv.org/abs/2604.11454) specifies the syntax, type system and semantics of the GraphAlg and GraphAlg Core languages, as well as their relation to [MATLANG](https://arxiv.org/abs/1709.08359).
